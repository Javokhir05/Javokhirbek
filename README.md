## 📂 Getting Started

Clone the repository:

```bash
git clone https://github.com/Javokhir05/Javokhirbek.git
```

Navigate to the project:

```bash
cd Javokhirbek
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
